특정 규칙 삭제하고 순서 바꾸기 방법

로그 저장 위치

우분투 = /var/log/kern.log
	/var/log/syslog

로키 = 	/var/log/messages
	/var/log/firewalld


iptables -D 할때 지정한 규칙 풀네임

iptables -S 로 설정 확인 후
그대로 -D 사용 가능


iptables -X 체인 초기화
사용자가 만든 사용자 정의 체인
기본 체인 삭제 불가
삭제하려는 체인은 비어 있어야 함. 규칙이 남아 있으면 삭제 실패.


iptables -F 모든 체인(INPUT, OUTPUT, FORWARD 등) 규칙 삭제
(특정 체인을 지정하면 그 체인의 규칙만 삭제)
체인은 남아 있음, 단순히 체인 안의 규칙 목록만 비움
