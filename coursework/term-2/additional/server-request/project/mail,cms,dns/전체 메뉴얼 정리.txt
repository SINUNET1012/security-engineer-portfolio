MAIL
=====================================================
1. 아파치, php(8.4) 설치
2. postfix 설치
2-1. 메일 전용 디렉터리 준비 / 소유권, 권한 설정
- /home/mails/mail
- touch /home/mails/mail/inbox (mbox 파일 생성)
- chown -R mails:mails /home/mails/mail (소유권 이전)
- chmod -R 700 /home/mails/mail (보안을 위해 권한 제한)

2-1. postfix 설정(SMTP)
/etc/postfix/main.cf
- home_mailbox = mail/inbox
- mail_spool_directory =

- smtpd_relay_restrictions = permit_mynetworks permit_sasl_authenticated defer_unauth_destination
- myhostname = mails.bs.com
- mydomain = bs.com
- myorigin = $mydomain

- mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
- mynetworks = +허용할 네트워크 대역 추가

3. dovecot 설치
3-1. dovecot 설정(IMAP)

/etc/dovecot/conf.d/10-auth.conf
- disable_plaintext_auth = no
- auth_mechanisms = plain login

- auth_worker_max_count = 100 (로그인 횟수 제한)
- auth_failure_delay = 0

/etc/dovecot/conf.d/10-mail.conf
- mail_location = mbox:~/mail:INBOX=~/mail/inbox

/etc/dovecot/conf.d/10-ssl.conf
- ssl = no
