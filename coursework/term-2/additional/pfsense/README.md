# pfSense lab (artifacts)

This coursework item was mainly stored as a VMware VM (e.g., `.vmdk`, `.vmx`, `.nvram`).
Those binary/VM image files are intentionally excluded from this GitHub portfolio repo.

If you want to publish this lab, a good approach is to re-export **text-based** artifacts instead:

- Network diagram (PNG/SVG)
- Firewall/NAT rules screenshots
- Exported configs (XML) or sanitized notes (MD/TXT)
