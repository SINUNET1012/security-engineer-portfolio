개념
Number of processors (프로세서 수 / 소켓 수):
물리적 의미: 컴퓨터의 메인보드에 꽂을 수 있는 물리적인 CPU 칩(소켓)의 개수를 의미합니다. 고성능 서버에는 보통 2개 이상의 CPU 소켓이 있습니다.
가상 머신 의미: 게스트 OS(Security Onion)가 인식하게 될 가상 CPU 소켓의 개수입니다.

Number of cores per processor (프로세서 당 코어 수):
물리적 의미: 하나의 CPU 칩 안에 들어있는 독립적인 처리 장치(코어)의 개수입니다. 요즘 우리가 사용하는 CPU는 대부분 멀티코어(4코어, 8코어 등)입니다.
가상 머신 의미: 하나의 가상 CPU 소켓에 몇 개의 코어가 있는 것처럼 보여줄지를 의미합니다.
