2. config.inc.php 파일을 수정해준다. (password만)
- vim /var/www/html/DVWA/config/config.inc.php

3. vim cd /etc/php/8.4/apache2/php.ini 설정파일에서 3가지 항목 on으로 변경

/etc/php/버전 번호/apache2/ 에서 버전 번호가 각자 다를 수 있음 

 - display_errors=On
 - display_startup_errors=On
 - allow_url_include=On

바뀐 php 설정 적용 apachectl restart


4. mod_rewrite는 Enable 로 변경
- a2enmod rewrite
- apachectl restart
