수업내용 명령어--------------------
-PE  (ICMP Ping) → 기본 ICMP 에코로 호스트 살아있는지 확인
-PS  (SYN Ping) → 지정 포트에 SYN 보내서 생존 여부 확인
-PA  (ACK Ping) → ACK 보내고 RST 응답으로 생존 확인
-PU  (UDP Ping) → UDP 보내고 ICMP 오류로 생존 확인
-Pn  (No Ping) → 호스트 발견 생략하고 바로 스캔

-sT  (TCP Connect) → 3-way handshake로 모든 연결 확인
-sS  (SYN Scan) → SYN만 보내고 RST로 끊는 스텔스 스캔
-sU  (UDP Scan) → UDP 특성 기반 포트 상태 추정
-sN  (NULL Scan) → 플래그 없이 보내 방화벽/OS 반응 확인
-sF  (FIN Scan) → FIN만 보내 포트 반응 분석
-sX  (XMAS Scan) → 여러 플래그 켜서 비정상 반응 분석

-sV  (Version Scan) → 서비스 버전 및 배너 분석
-O   (OS Detection) → TTL/윈도우/플래그 기반 OS 지문 분석

-T0  (Paranoid) → 매우 느리고 조용한 스캔
-T1  (Sneaky) → 느리고 은밀하게 스캔
-T2  (Polite) → 속도 제한하며 부담 적게 스캔
-T3  (Normal) → 기본 속도
-T4  (Aggressive) → 빠른 스캔
-T5  (Insane) → 매우 빠르고 시끄러운 스캔

-f   (Fragment) → 패킷 쪼개서 방화벽 우회 시도
-D   (Decoy) → 가짜 IP 섞어 추적 혼란 유발
-S   (Spoof IP) → 출발지 IP 위조
--scan-delay  (Delay) → 패킷 간 시간 지연 주기
--max-rate    (Rate Limit) → 초당 전송 패킷 수 제한
--max-retries (Retry Limit) → 재전송 횟수 제한

-D RND:5  (Random Decoys) → 랜덤 IP 5개 섞어 디코이 스캔
-S <IP>   (Source Spoof) → 출발지 IP를 <IP>로 위조

-iL <file>  (Input List) → 대상 IP 목록 파일로 입력
-p $(cat <file>)  (Port List) → 파일의 포트 목록 불러오기
-p $(paste -sd "," <file>) → 포트 목록을 , 로 이어서 사용

-oN  (Normal Output) → 일반 텍스트 파일로 저장
-oG  (Grepable Output) → grep 사용하기 좋은 형식
-oX  (XML Output) → XML 형식으로 저장
