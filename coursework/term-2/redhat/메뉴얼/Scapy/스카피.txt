# Scapy

## 정의
Scapy는 파이썬으로 작성된 강력하고, 인터랙티브한 패킷조작 도구이다.
사용자가 네트워크 패킷을 생성, 전송, 캡처, 분석 할 수 있게 해주어, 네트워크 탐색, 스캔, 테스트, 보안
분석 및 공격 도구 개발 등 다양한 용도로 활용된다.

## 주요 기능 및 특징.

### 패킷 생성 및 조작
- 계층별 구성 : 스카피는 OSI 7계층 또는 TCP/IP 4,5계층 모델에 따라 각 계층의 필드를 정의하여 패킷을
                   쉽게 조립할 수 있다.
- 커스터마이징 : 사용자가 패킷의 모든 필드를 자유롭게 설정하고 위조할 수 있다. 

### 패킷 전송
- 생성한 패킷을 네트워크 인터페이스를 통해 전송할 수 있다.
- 응답을 기다리며 요청 패킷을 보내고 응답 패킷을 받아서 요청과 응답을 자동으로 매칭하는 기능도 제공
  한다.

### 패킷 캡처 및 스니핑
- sniff()함수를 사용하여 네트워크를 통과하는 패킷을 캡처하고 필터링할 수 있다.
- 캡처된 패킷은 쉽게 분석하고 재사용할 수 있는 구조로 저장된다.

### 패킷 분석
- 캡처된 패킷의 상세 정보를 계층별로 쉽게 분해하여 보여준다.


## 활용 분야

### 1. 네트워크 보안 테스트 및 모의 해킹
- 포트 스캐닝 : 커스텀 TCP / UDP 패킷을 만들어 포트의 상태를 확인한다.
- ARP 스푸핑, DNS 스푸핑 : 위조된 패킷을 전송하여 중간자 공격등을 수행한다.
- DoS / DDoS 공격 테스트 : 비정상적인 패킷을 대량으로 생성하여 전송하는 테스트를 할 수 있다.

### 2. 네트워크 디버깅 및 문제 해결
- 네트워크 상에서 특정 프로토콜의 작동을 확인하거나, 사용자 정의된 방식으로 통신을 시도하여 문제를 
  진단한다.

### 3. 프로토콜 연구 및 개발
- 새로운 프로토콜의 패킷 구조를 테스트하거나, 표준 프로토콜의 비표준 동작을 연구하는 데 사용된다.

### 4. 교육
- 네트워크 프로토콜의 작동 원리를 이해하고 직접 패킷을 다루는 실습환경을 제공한다.

# Wireshark를 활용한 패킷 분석
=> 스카피 공격의 특징은 일반적인 트래픽과 다른 비정상적인 필드값에 있다.

- SYN Scan : TCP Flags: SYN은 있으나, 응답으로 SYN/ACK 대신 RST가 반복적으로 오거나, 세션 완성이
                없는 패킷이 특정 IP에서 다수 발생.
- ARP 스푸핑 : 특정 MAC 주소에 대해 동일한 IP 주소가 반복벅으로, 매우 짧은 간격으로 보고되는 ARP 
                   Reply 패킷 확인 (게이트웨이 MAC이 변경됨)
- Malformed / Fragmented : TTL 값이 비정상적으로 낮거나, 패킷의 IP 단편화 필드가 이상하게 설정된 패킷.


# 서버 / 네트워크 로그 분석 (SIEM 연동 가정)
=> 블루팀은 스카피 공격으로 인해 생성되는 시스템 로그 및 네트워크 장비 로그를 분석하여 침해시도를
     탐지해야한다.

## 방화벽 / IDS / IPS 로그 
- 짧은 시간 내에 대량의 연결 시도(SYN)가 기록되면 포트 스캔 이벤트로 탐지된다.
- 사전 정의된 규칙을 위반하는 비정상적인 TCP 플래그 조합 패킷이 기록될 경우 경보(Alert)가 발생.

## 운영체제(OS) 로그
- 공격 시도 직후에 실패한 인증 시도나 비정상적인 서비스 재시작 등 연쇄적인 시스템 로그 변화를 확인한다.
