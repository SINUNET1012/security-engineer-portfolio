# Masscan

1. 정의
- 대량 IP 포트 스캔할 수 있는  인터넷 규모의 포트 스캐너
- 6분 이내에 전체 인터넷을 스캔하여 단일 시스템에서 초당 천만 개의 패킷을 전송할 수 있음.
- 과거에는 Nmap을 사용했지만, 큰 범위를 스캔할 때는 속도가 느려져 요즘은 Masscan을 사용한다.
- 비동기식 전송 : 응답을 기다리지 않고, 패킷을 계속 쏟아낸다. 송신 스레드와 수신 스레드가 분리되어있어
  보낸 패킷에 대한 응답이 올때까지 기다리지 않는다.
- 버전탐지 불가 : 상세한 서비스 버전이나 OS 종류를 알아내는 데는 적합하지 X

- 비유 : 우편 배달부가 모든집의 초인종을 누르고 ,문이 열리는지만 확인하고 바로 다음집으로 뛰어가는 겉과 같다.
           (대화는 X)


# Masscan을 쓰는 경우.
- 방대한 범위의 네트워크 대역을 스캔해야 할 때.
- 특정 포트가 열려있는 서버 리스트를 빠르게 확보하고 싶을 때
- 정밀 분석전, 살아있는 호스트를 1차적으로 필터링할 때.

# Nmap을 쓰는 경우.
- 특정 타켓에 대해 깊이 있는 보안 진단을 수행할 때
- 서버의 운영체제, 실행 중인 서비스의 저번, 취약점 여부를 파악해야 할 때.
- Masscan으로 1차 필터링한 리스트를 바탕으로 상세 분석을 할 때.

# 효율적으로 쓰는 법.
- 1단계(Masscan): 전체 네트워크 대역을 빠르게 훑어 포트가 열린 활성 IP 리스트를 추룰한다.
- 2단계(Nmap): 추출된 IP리스트에 대해서만 Nmap을 돌려 상세 취약점 및 버전 분석을 수행한다.



# 구조
sudo masscan [IP대역] -p [포트] [옵션]

# 옵션

## 포트 지정(-p,--ports)
- 단일 포트 : -p80 
- 다중 포트 : p80,443,22 (콤마로 구분하고 띄어쓰기는 하지 말자)
- 범위로 지정 : -p1-1000
- 전체 포트 : -p0-65535
- UDP 포트: U:53(UDP는 포트 번호 앞에 U:를 붙인다.)

## 속도 조절(--rate) -> 초당 보낼 패킷 수를 설정한다. 기본값은 100이다.
- --rate 1000 : 안전한 속도 (일반적인 네트워크)
- --rate 10000 : 빠른 속도 (기가비트 환경 권장)
- --rate 10000000: 이론상 최대 속도(특수 하드웨어 / 드라이버 필요함.)
 
** 주의 : 무작정 속도를 높이면 공유기가 뻗거나, 패킷 손실이 발생해 스캔 정확도가 떨어진다. 가정용 네트워크는
            1000~5000 정도를 권장한다.

## 네트워크 인터페이스 지정 (-e, --router-ip)
-> Masscan은 OS의 라우팅 테이블을 무시하므로, 가끔 어디로 패킷을 보내야할지 모르는 경우가 있다.

- -e eth0 : 특정 네트워크 인터페이스를 강제로 지정한다.
- --router-ip [게이트워이 IP] : 게이트웨이 IP를 명시한다.


## 결과저장 (-oX, -oJ, -oL)
-> 화면에 출력되는 내용은 너무 빠르게 지나가므로 파일로 저장해야한다.

- -oX filename.xml : XML 형식 저장 (nmap과 호환된다.)
- -oJ filename.json :  JSON 형식 저장 (파싱하기 좋음)
- -oL filename.txt : 간단한 리스트 형식 저장
- > filename.txt : 리눅스 표준 출력 리다이렉션 사용 가능.
