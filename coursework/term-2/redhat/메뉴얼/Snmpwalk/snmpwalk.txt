# Snmpwalk

# 정의
- snmpwalk는 SNMP(Simple Network Management Protocol)를 사용하는 네트워크 장치나 시스템에서 정보를
  검색하는 데 사용되는 명령줄 유틸리티이다.
- 주요 기능은 지정된 MIB(Management Information Base) 서브트리를 따라 순차적으로 쿼리를 수행하여, 해당 서브
  트리에 속한 모든 변수와 그 값들을 검색하고 표시하는 것이다.

# 주요 기능 및 작동 방식

## 순차적 쿼리
- 일반적인 SNMP GET 명령은 단일 변수의 값만 가져온다.
- snmpwalk는 주어진 객체 식별자(OID)로 시작하여, 해당 OID 아래의 모든 정보를 한 번의 명령으로 재귀적으로
  요청하고 검색한다.

## MIB 서브트리 탐색
- 네트워크 장치의 모든 관리 정보는 계층적 데이터베이스인 MIB에 저장된다.
- snmpwalk에 특정 OID를 입력하면, 해당 OID를 뿌리로 하는 서브트리 전체를 탐색한다.
  예를 들어, 시스템 인터페이스 정보를 담당하는 OID를 입력하면, 모든 네트워크 인터페이스의 이름
  ,상태, 트래픽 통계 등을 한번에 가져올 수 있다.

## SNMP 버전 지원
- snmpwalk는 일반적으로 SNMPv1, SNMPv2c,SNMPv3를 포함한 다양한 SNMP 버전을 지원한다.

## 정보 출력
- 명령 실행 결과는 보통 OID와 그에 해당하는 값의 쌍으로 출력되어, 장치의 상태에 대한 포괄적인
  스냅샷을 제공한다.

# 구조

snmpwalk [옵션] <에이전트 IP주소 or 호스트 이름> <커뮤니티 문자열> <시작OID>

# 옵션
-> snmpwalk 명령은 다양한 옵션을 제공하여 쿼리할 snmp버전, 보안설정,출력 형식등을 제어할 수 있다.
   
## 일반 옵션
- -h : 간단한 사용법 요약을 출력한다.
- -v <버전> : 사용할 snmp 버전을 지정한다.
- -r <재시도> : 에이전트로부터 응답을 받지 못했을 경우 재시도 횟수를 지정한다.
- -t <타임아웃> : 응답을 기다릴 시간을 지정한다.
- -O <출력형식> : 출력형식을 제어한다. 예를 들어 OID를 숫자로만 출력하거나(n), MIB이름으로 출력한다.(s)
- -P : MIB 파일을 사용 할 때 MIB 모듈을 지정한다.
- -m : 로드할 MIB 파일을 지정한다.

## SNMPv1 / SNMPv2c 관련된 옵션
-> SNMPv1과 v2c는 커뮤니티 문자열을 사용하여 접근권한을 제어한다.

- -c<커뮤니티> : 커뮤니티 문자열을 지정한다. (읽기 권한을 가진 문자열을 사용해야한다.)
- -C <옵션> : 다양한 세부 제어 옵션을 지정한다. 예를 들어, snmpwalk가 GETNEXT 대신 GETBULK를 사용하도록
                  설정할 수 있습니다.(SNMPv2c에서 유용)

## SNMPv3 관련 옵션 (보안 및 인증)
-> SNMPv3는 사용자 기반 보안 모델(USM)을 사용하며, 사용자 이름, 인증, 암호화 옵션을 제공한다.
    약간 더 복잡하다.

- -u <사용자 이름> : 보안 사용자 이름을 지정한다.
- -l <레벨> : 보안 레벨을 지정한다.
   noAuthNoPriv (인증 / 암호화 없음)
   authNoPriv (인증 사용, 암호화 없음)
   authPriv (인증 및 암호화 모두 사용)
- -a <프로토콜> : 인증 프로토콜을 지정합니다. (예: MD5 or SHA)
- -A <암호> : 인증 암호를 지정합니다.
- -x <프로토콜> : 암호화 프로토콜을 지정합니다. (authPriv 사용시 필요함) ex) DES, AES
- X <암호> : 암호화 암호를 지정한다. (authPriv 사용시 필요)

## 출력 형식 제어 옵션(-O) 상세
-> -O 옵션은 snmpwalk의 결과를 사용자가 원하는 형태로 볼 수 있도록 도와주는 매우 유용한 옵션이다.
- -n : OID를 숫자 형태로만 출력한다.
- -s : OID의 마지막 심볼만 출력한다.
- -S : OID의 전체 심볼을 출력한다.
- -q : 출력에서 MIB 식별자를 생략하고 값만 출력한다. -> 스크립팅에 유용함.
- -Q : 출력에서 타입정보도 생략한다.
