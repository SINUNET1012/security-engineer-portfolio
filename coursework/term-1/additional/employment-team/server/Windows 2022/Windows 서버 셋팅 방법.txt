19. 모바엑스텀 연결 (ssh버전)
 - 검색창에 선택적 기능 추가 검색
 - + 아이콘인 기능 추가 클릭
 - OpenSSH 서버 검색 및 체크 후 설치 클릭
 - 창 닫고 "서비스" 검색
 - OpenSSH SSH Server 찾고 클릭 왼쪽에 서비스 시작 버튼 클릭하여 서버 프로그램 실행 (껐다 켜도 자동으로 실행되도록 하기 위해 : 오른쪽 클릭 - 속성 - 시작유형 : 자동 - 확인 클릭)
 - 정상 작동 확인을 위해 cmd창 열어서 ssh administrator@127.0.0.1 입력
 - 모바엑스텀에서 PC IP 입력해서 접속

20. 모바엑스텀 연결 (rdp 버전)
 - 서버 관리자를 켠다(아까 내려놓은거)
 - 로컬 서버를 들어간다
 - 원격 데스크톱이 비활성화 되어있는 것을 확인하고 파란 글자를 클릭한다
 - 원격 탭에서 이 컴퓨터에 원격 연결 허용을 선택하고 확인을 누른다
 - 윈도 원격프로그램에서 "이 컴퓨터에 대한 원격연결 허용" 밑에 네모 체크 해제해야함
 - 확인을 누른다
 - 새로고침 버튼을 누르고 사용으로 변한 것을 확인한다.
 - 모바엑스텀으로 세션을 만드는데 rdp프로토콜을 사용하고 IP주소를 적고 OK를 누른다
 - 다른 옵션 선택 클릭
 - 다른 계정 사용을 클릭한다
 - 사용자 이름을 administrator, 암호는 이전에 설정한 것을 입력하고 로그인한다
