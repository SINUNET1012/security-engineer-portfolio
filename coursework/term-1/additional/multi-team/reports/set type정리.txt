1. set.add(elem)
 집합에 요소 하나를 추가합니다.
 이미 있는 요소를 추가하려 해도 중복 없이 유지됩니다.

a={1,2,3}
a.add(5)
print(a)

결과값: {1, 2, 3, 5}

a={1,2,3}
a.add(3)
print(a)

결과값: {1, 2, 3}


2. set.clear()
 집합의 모든 요소를 제거합니다.
 결과적으로 빈 집합이 됩니다.

a ={1,2,3}
a.clear()

print(a)

결과값: set()

3. set.copy()

 집합의 얕은 복사본을 만듭니다.
 원래 집합과는 별개인 새로운 집합입니다.

a1 ={1,2,3}
a2 = a1.copy()

print(a2)

결과값:{1,2,3}

a1.add(4)
print(a1)
print(a2)

결과값: 
{1, 2, 3, 4}
{1, 2, 3}

4.difference 함수
차집합을 구하는 함수, 기존 데이터는 유지되므로 새로운 변수에 저장하여 사용

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
c = a.difference(b)
print(c)
#결과값 : {1, 2}


5.difference_update 함수
두 집합의 차집합을 구하고, 기존 집압에 바로 적용하는 함수
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
a.difference_update(b)
print(a)
#결과값 : {1, 2}


6.
discard함수
#집합에서 x제거, 없으면 그냥 지나감
s = {1, 2, 3}
s.discard(2)
print(s)  # {1, 3}

s.discard(5)  # 없어도 에러 없음
print(s)  # {1, 3}

7.intersection()
교집합 반환 (& 연산과 동일)
a = {1, 2, 3}
b = {2, 3, 4}
print(a.intersection(b))  # {2, 3}

8.intersection_update()
교집합으로 자기 자신을 갱신
a = {1, 2, 3}
b = {2, 3, 4}
a.intersection_update(b)
print(a)  # {2, 3}  # a가 교집합으로 바뀜 

9.
isdisjoint 함수
set type과 set type이 서로 겹치는 요소가 하나도 없으면 True를 반환, 
하나라도 겹치는 요소가 있으면 False를 반환
a = {1, 2}
b = {3, 4, 5}
c = {4, 5}
print(a.isdisjoint(b)) # 결과값 : Ture
print(b.isdisjoint(c)) # 결과값 : False
