단계 1. "시작" 버튼을 클릭하여 Server Manager
단계 2. Server Manager 창 왼쪽의 "로컬 서버"를 클릭, 원격 데스크톱이 "비활성화"되어 있다면 "활성화"

단계 4. "원격 데스크톱" 탭에서 "이 컴퓨터에 원격 연결 허용"을 선택
단계 5. 위 단계를 수행한 후 경고 메시지가 표시됩니다. "확인"을 클릭
