vmware 서버 네트워크 설정 custom으로 vmnet으로 변경 후 실행
서버 아이피 설정에 맞게 수정 후(nmtui) reboot

GNS에서 클라우드에 vmnet 번호에 맞게 수정 후 포트 생성

라우터 콘솔 접속
conf t
int 포트번호
ip add 설정 아이피 서브넷
no sh
end
####라우터 포트 아이피 설정

conf t
ip route (연결 할 네트워크 아이디) (서브넷) (내 라우터랑 연결된 상대 라우터 시리얼 포트 아이피)
###여러개로 나눠진 네트워크는(subnet) 다시 합쳐서(supernet) 설정이 가능하다.
### 192.168.0.0/25, 192.168.0.128/25 > 192.168.0.0/24

###만약 라우터가 하나만 연결되어있으면 outside 포트가 하나라서 default등록 하나로 설정을 끝낼 수 있다.
###STUB 상황
###ip route 0.0.0.0 0.0.0.0 (내 라우터랑 연결된 상대 라우터 시리얼 포트 아이피)

###외부 네트워크는 축약 등록하고 내부 네트워크는 상세 등록하여 관리
###Static 라우팅 설정


conf t
int 내부망(inside)과 연결된 포트 번호
ip nat inside
잠시 기다리고
exit
int 외부망(outside)과 연결된 포트 번호
ip nat outside
exit
ip nat inside source static (통신을 시도하는 내부PC의 IP) (내 라우터의 시리얼 포트 아이피)
###스태틱 nat 설정
