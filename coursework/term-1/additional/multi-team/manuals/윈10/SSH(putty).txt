putty로 해당 ip를 접속하면 비밀번호 설정이 없어 닫힘

ESW1(config)#line ? // 외부에서 접근하기 위한 방법 모음
# ? 사용가이드(다음 명령어)

  <0-166>  First Line number
  aux      Auxiliary line		/
  console  Primary terminal line	/ 실제 포트 접속
  tty      Terminal controller		/ 원격 접속 프로토콜
  vty      Virtual terminal		/ 원격 접속 프로토콜
  x/y      Slot/Port for Modems

ESW1(config)#line vty 0 4 (0~4 동시 접속 5개 제한)
ESW1(config-line)#password cisco (비밀번호 설정 : cisco)

RSA 암호화

ESW1(config)#crypto key generate rsa
보안 통신에 필수적인 RSA 암호화 키를 생성

======================================================
사용자 계정 설정
ex) ID와 Password 방식 (향후 인증키도 사용해보자)

ESW1(config)# username [이름] privilege 15(관리자)

ESW1(config)# username lemon privilege ?
  <0-15>  User privilege level	(권한의 등급 단계)
				(보통 서버 관리자의 경우 7~8 부여)
ESW1(config)# username lemon privilege 15 password cisco

======================================================
VTY 설정

ESW1(config)# line vty 0 4

ESW1(config-line)#transport input ?
  all      All protocols
  lapb-ta  LAPB Terminal Adapter
  mop      DEC MOP Remote Console Protocol
  none     No protocols
  pad      X.3 PAD
  rlogin   Unix rlogin protocol
  ssh      TCP/IP SSH protocol (유일하게 보안성 검증됨)
  telnet   TCP/IP Telnet protocol
  udptn    UDPTN async via UDP protocol
  v120     Async over ISDN

ESW1(config-line)#transport input ssh (ssh만 사용함)

------------------------------------------------

ESW1(config)#ip ssh time-out ?
  <1-120>  SSH time-out interval (secs) (세션 종료 시간)

ESW1(config)#ip ssh time-out 60

------------------------------------------------

ESW1(config)#ip ssh authentication-retries ?
  <0-5>  Number of authentication retries

ESW1(config)#ip ssh authentication-retries 3

------------------------------------------------

ESW1(config)#line vty 0 4
ESW1(config-line)#transport input ssh (ssh로 연결 전환)
ESW1(config-line)#login local (로컬 계정으로 로그인)
