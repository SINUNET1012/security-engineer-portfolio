Storage Server 구축하기

iSCSi (Internet Small Computer System Interface)

스토리지 장치에 블록(Block) 수준으로 접근할 수 있도록 하는 스토리지 네트워킹
서버는 클라이언트 디스크를 볼 수 없음

1. 서버에 iscsi 생성

서버에 HDD를 추가하고

클라이언트에 분배하기

=====================================================================

1.1. 패키지 설치
targetcli 도구를 사용하여 iSCSI Target을 구성합니다.

dnf install targetcli -y
dnf install iscsi-initiator-utils -y  / apt install open-iscsi

systemctl enable --now target	(서버)
systemctl enable --now iscsid	(클라이언트)
systemctl start iscsid



1.2. LUN (저장 공간) 준비 및 백스토어 생성

/dev/sdb 디스크 전체를 사용한다고 가정하고, targetcli 쉘 명령어를 단일 명령어로 실행합니다.

주의: /dev/sdb는 비어 있는 디스크여야 하며, 기존 데이터는 모두 삭제됩니다.

# /dev/sdb가 존재하는지 확인 (필요 시 vmware에서 새 디스크 추가)
fdisk -l
lsblk

# block 백스토어 생성 (디스크 전체를 raw 블록 장치로 사용)
주의: 이 명령은 /dev/sdb 내의 모든 기존 데이터를 삭제합니다.

# targetcli 진입
/>


targetcli /backstores/block create name=disk1 dev=[/dev/sdb]

targetcli /backstores/block create name=disk1 dev=/dev/sda

1.4. iSCSI Target 및 LUN( ≒ 파티션) 구성
Target IQN과 포털(Target 서버 IP)을 설정하고 LUN을 연결합니다.

# iSCSI Target 생성 (IQN 지정)
IQN : iSCSI 네트워크에 참여하는 모든 장치(서버와 스토리지)에 할당되는 고유한 이름

	iqn.YYYY-MM.도메인역순:고유문자열

LUN 	: 아파트의 호실
iQN	: 도로명 주소


iqn 확인법
~~~~

윈도우 : iscsi 초기자 속성 / 구성 / 초기자 이름 :
iqn.1991-05.com.microsoft:tj

리눅스 : cat /etc/iscsi/initiatorname.iscsi (클라이언트용 설치되어 있어야 함)
InitiatorName=iqn.1994-05.com.redhat:da8db1236b51
InitiatorName=iqn.2004-10.com.ubuntu:01:68299635f96d
InitiatorName=iqn.1994-05.com.redhat:9832e6c91b6
...

~~~~

도메인역순 ex) example.com / com.example

targetcli /iscsi create [iqn.2025-10.com.rocky9:storage.target1]

targetcli /iscsi create iqn.2025-10.com.8team:DISK1


# ACL 생성 (Windows 초기자의 실제 IQN 사용)
targetcli /iscsi/iqn.2025-10.com.8team:disk1/tpg1/acls create [접속 컴퓨터의 IQN]

# ACL 경로 이동 및 권한 부여
cd /iscsi/iqn.2025-10.com.8team:disk1/tpg1/acls

create [접속 컴퓨터의 IQN]
create iqn.1991-05.com.microsoft:tj
create iqn.2004-10.com.ubuntu:01:68299635f96d

# 포트 설정 (Target 서버의 IP 주소 바인딩)
targetcli /iscsi/[2.2단계에서 지정한 IQN]/tpg1/portals create [192.168.1.10]

targetcli /iscsi/iqn.2025-10.com.8team:disk1/tpg1/portals create 172.16.5.11

# LUN 연결 (disk1 백스토어를 LUN으로 노출)
targetcli /iscsi/[2.2단계에서 지정한 IQN]/tpg1/luns create /backstores/block/disk1

targetcli /iscsi/iqn.2025-10.com.8team:disk1/tpg1/luns create /backstores/block/disk1

# 설정 저장 및 현재 구성 확인
targetcli saveconfig (일반 쉘에서 작업했다면)
exit (targetcli 쉘 내부에서 작업했다면)

targetcli ls
