스위치 ---> 기능 : L2 MAC주소 제어
트랜스패런트 브릿징(Transparent Bridging)

1. Learning (학습) : 주황색(학습중) --> 녹색(학습완료)
                     현재 포트에 연결된 상대방 호스트의 MAC 학습
    mac table 생성

2. Aging    (나이) : (3분) 현재 포트의 사용이 3분간 없으면 MAC-Table에서 삭제
3. Filtering (필터링) : 현재 포트에서 들어온 정보를 다시 그 포트로 전달하지 않는다.
        S.MAC와 D.MAC가 같은 경우 프레임을 전달하지 않는다.
        관리자에 의해서 필터링 규칙을 작성할 수 있다.(Port-Security)
4. Forwarding(전달) : 프레임의 L2헤더를 읽고 그 중 D.MAC 확인
                      MAC-Table과 비교 후 특정 인터페이스로만 전달한다.
5. Flooding (홍수)  : 프레임의 L2헤더를 읽고 그 중 D.MAC 확인
                      MAC-Table과 비교 후 MAC-Table에 존재하지않는 주소라면
                      플러딩한다.
