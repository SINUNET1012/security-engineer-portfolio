다이렉트 케이블 : EIA/TIA 568B (Copper Straight-Through=UTP)
                               색깔배열        구리
568B-568B(둘다B) = 다이렉트 케이블 : 서로 다른 장비 연결시 -> 네트워크관리사시험 
568A-568B = 크로스 케이블 : 서로 같은 장비 연결시

Layer 1 : Physical Layer : 물리계층
	키워드 : Cable → 선 ⇒ 포설
물리적 특성 : 기계적 / 전기적 / 절차적  -> 네트워크관리사시험

 1. UTP : Unshield Twisted Pair : 실내
 2. STP : Shield Twisted Pair     : 실외
 3. FTP : Foil Twisted Pair (주의 : File transport protocol이랑 헷갈리지 않기)
 4. Coaxial : 동축케이블 : 동네 케이블 방송국
 5. Fibel : 광케이블

100BASE-T
속도 / 디지털 or 아날로그 / 거리 T=약100M(대략적으로 50M 일상에서는)

물리계층 장비
리피터(Repeater) -> 전달거리 연장-> 신호의 재생산 (디지털 신호)
**모든 네트워크 장비는 리피터의 역할을 한다.**
증폭기(Amplifier) -> 진폭을 확대 (아날로그 신호)

HUB : 전달되는 신호를 신호가 들어온 포트를 제외한 모든 포트로 재전송한다.
CoAxialSplitter : 다수를 분리해서 신호를 보낼 수 있음

스위치 ---> 기능 : L2 MAC주소 제어
트랜스패런트 브릿징(Transparent Bridging)

1. Learning (학습) : 주황색(학습중) --> 녹색(학습완료)r
                     현재 포트에 연결된 상대방 호스트의 MAC 학습
                     mac table 생성
2. Aging    (나이) : (3분) 현재 포트의 사용이 3분간 없으면 MAC-Table에서 삭제
3. Filtering (필터링) : 현재 포트에서 들어온 정보를 다시 그 포트로 전달하지 않는다.
        S.MAC와 D.MAC가 같은 경우 프레임을 전달하지 않는다.
        관리자에 의해서 필터링 규칙을 작성할 수 있다.(Port-Security)
4. Forwarding(전달) : 프레임의 L2헤더를 읽고 그 중 D.MAC 확인
                      MAC-Table과 비교 후 특정 인터페이스로만 전달한다.
5. Flooding (홍수)  : 프레임의 L2헤더를 읽고 그 중 D.MAC 확인
                      MAC-Table과 비교 후 MAC-Table에 존재하지않는 주소라면
                      플러딩한다.
