관리자 권한에서만 가능

arp -a : arp 검색
arp -d : arp 삭제

arp : 상대방의 ip를 통해 mac주소 알아내는 것
리버스arp : 상대방의 mac를 통해 ip주소 알아내는 것
gratuitous arp : 내 arp를 모두에게 브로드캐스트

proxy arp

                              CD(컬리전 도메인)         BD(브로드캐스트 도메인)
L1 장비 : HUB                      X                                  X
L2 장비 : 스위치                   O                                  X(ffff)
L3 장비 : 라우터                   O                                  O(255) -> 네트워크에서 차단

라우터 = L3주소(IP주소), 네트워크ID 추출 -> 자신의 라우팅 테이블과 비교
            모르는 목적지 주소가 들어오면 드랍
