        목적지 네트워크


사설 네트워크의 범위 지정 --> ACL

conf t
access-list 1 permit 192.168.0.0 0.0.0.255 <--- 사설 범위
            숫자                       --------- : not연산 (0=1, 1=0)

ip nat pool KONG ex)12.1.1.2 12.1.1.3 ->2개 netmask 255.255.255.0 <----공인 범위


NAT 설정
ip nat inside source     list 1      pool KONG
                             ------     ------------
                          사설IP대역   공인IP대역

ip nat inside source list 1 pool aaa
ip nat pool aaa 208.0.100.2 208.0.100.3 netmask 255.255.255.0
(공인 IP + secondary IP까지)
