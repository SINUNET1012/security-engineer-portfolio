변수 = 변하는 수
stack -> 변수 테이블 

레퍼런스 : 메모리 주소를 기억
ex) a=3 이라는 메모리 주소를 기억

변수를 선언 : 변하는 수 → 변수 → 메모리의 주소를 기억 → Data의 위치 : 리터럴

변수타입 변수명 = 리터럴
ex) int          a         =       3 (int a = 3)
변수타입     변수

C언어 = 수동, JAVA= 반자동, Python= 제일 큰 size

데이터 타입
1. 기본 타입
->선언된 변수의 값이 stack 영역에 저장
stack 영역 = 작성한 코드가 직접적으로 실행되는 영역

2. 확장 타입
->heap 영역에 데이터 저장

heap -> temporary(임시로 저장) : 작업이 완료됨과 동시에 사라짐

GC = garbage collector
-> 먼저 입력된 값을 감시하다 사용 안할 시 삭제(공간 정리)

맨 왼쪽 : 부호 비트 -> 0이면 양수, 1이면 음수

3. 논리형 데이터 타입 (bool/부울/불/Boolean)
	  : 참(true)과 거짓(false)이라는 두 가지 값만 갖는 데이터 타입
	  둘 중 하나의 값만을 갖는다.
		참 → 1 : 거짓이 아닌 모든 것
                거짓 → 0, False

	1Byte : 참조형 데이터타입인데 기본데이터타입으로 간주한다.

문자는 ' ', 문자열은 " "
\(역슬래시)n = 다음줄로
\(역슬래시)t = 공백4칸(Tab)
[ ]=인덱스 번호

a = "kong"
print("%10s"%(a)) # --> 10칸에 걸쳐서 결과값을 출력해라. 오른쪽 정렬한다.
print("%-10s"%(a)) # 왼쪽 정렬

print("{0:10}".format(a)) # 왼쪽 정렬                                                      
print("{0:^10}".format(a)) # 가운데 정렬                                                   
print("{0:*^10}".format(a)) # 가운데 정렬 공백을 "*"로 채운다. (기호는 변경가능)
