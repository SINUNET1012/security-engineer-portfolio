시작하기 전 ipv6는 아이피 등록을 통해
링크로컬 주소부터 얻고 프레임릴레이 브로드캐스트설정과 라우팅을 해야함. it means 'step by step'

관리자 모드 > 유니캐스트 라우팅 설정
인터페이스 > 프레임릴레이 설정
인터페이스 > ipv6 enable > ipv6 add ~~

R1
conf t
ipv6 unicast/routing

int s1/0
enc fra
no sh

int lo 0
ipv6 enable
ipv6 add 2001::1:1:1:1/64

int s1/0.1 mul
ipv6 enable
ipv6 add 2000::10:0:0:1/64
