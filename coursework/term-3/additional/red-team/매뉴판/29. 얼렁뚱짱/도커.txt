도커 작업 순서 정리
1.Dockerfile 작성 (환경 정의 단계)

목적: “이 서비스는 이런 환경에서 실행된다” 정의

FROM golang:1.9
WORKDIR /echo
COPY server.go /echo
CMD ["go", "run", "/echo/server.go"]

2. 이미지 빌드 (설계도를 실체로 만듦)
 목적: 재사용 가능한 실행 환경 생성
docker image build -t go:latest .

확인:
docker image ls
이 상태:
이미지 있음
컨테이너 없음
→ 정상


3️. 컨테이너 단독 실행 (단일 테스트용)

목적: 이미지 정상 동작 확인
docker container run -d -p 8081:8080 jenkins:2.142-slim

확인:
docker container ls
이 단계는:
실습
빠른 테스트
디버깅용




4. 컨테이너 관리 기본 명령 (운영 필수)
중지 / 재시작
docker container stop <컨테이너명>
docker container restart <컨테이너명>
삭제
docker container rm <컨테이너명>

 이름 ≠ 이미지
컨테이너 이름에 :latest 붙이면 틀린 명령


5️. 컨테이너 로그 / 내부 접근 (운영 디버깅)
로그
docker container logs -f <컨테이너명>

내부 접속
docker container exec -it <컨테이너명> sh



6️. 여러 컨테이너 필요해지면 → docker-compose (핵심 전환점)

목적: “여러 서버를 하나의 서비스처럼 관리”




docker-compose.yml 작성
version: "3"
services:
  echo:
    image: go:latest
    ports:
      - "9000:8080"

실행 (이게 핵심 명령)
docker compose up -d
