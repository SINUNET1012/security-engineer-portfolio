dig 사용법
1. 단계: 해당 도메인의 네임 서버(NS) 목록 찾기
먼저 해당 도메인이 어떤 DNS 서버를 쓰고 있는지 물어봐야 합니다. dig 명령어로 NS(Name Server) 레코드를 조회하면 됩니다.

명령어: dig [도메인] NS

예시: dig js.com NS

결과: ANSWER SECTION 부분에 ns1.js.com, ns2.js.com 같은 서버 이름들이 나옵니다. 이들이 바로 우리가 찔러볼 대상 DNS 서버의 이름입니다.

2. 단계: 네임 서버의 IP 주소 확인하기
이제 찾은 네임 서버 이름(ns1.js.com)이 실제로 어떤 IP를 쓰는지 알아야 합니다.

명령어: dig [네임서버_이름]

예시: dig ns1.js.com

결과: ANSWER SECTION에 해당 서버의 IP 주소가 출력됩니다. 만약 js.com의 네임 서버가 1.1.1.1이라면, 이 IP가 바로 AXFR 공격 대상이 됩니다.

3. 최종 단계: 알아낸 IP로 AXFR 시도
이제 아까 배운 명령어에 방금 찾은 IP를 넣으면 됩니다.

명령어: dig @[알아낸_IP] [도메인] AXFR

예시: dig @1.1.1.1 js.com AXFR
