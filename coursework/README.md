# Coursework (교육/팀 프로젝트 산출물)

이 폴더는 `Y:\` 아래에 있던 교육/팀 프로젝트 자료를 포트폴리오 용도로 정리한 복사본입니다.  
원본 파일/폴더는 **이동/삭제/이름 변경 없이 그대로 유지**하고, 레포에는 **선별된 파일만 복사**했습니다.

## 정리 기준
- VM/ISO/설치파일 등 포트폴리오에 불필요한 대용량 바이너리는 제외
- 임시/잠금 파일(예: `~$*.docx`) 제외
- 사람 이름이 포함된 경로/파일명은 포트폴리오 공개를 위해 일부 익명화

## 구성
- `term-1/` : 1차 프로젝트 기획안/결과보고서
- `term-2/` : 2차 프로젝트(네트워크/서버/레드/퍼플) + RedHat 실습 자료
- `term-3/` : 3차 프로젝트(기획 그림/DB정리 등) + 네트워크 실습 자료(야르웍스)
